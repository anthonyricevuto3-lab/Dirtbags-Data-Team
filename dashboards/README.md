# Dirtbags Dashboards

Internal read-only dashboards for data visualization and analysis.

## Running Dashboards

### Arsenal Dashboard

```bash
streamlit run dashboards/arsenal_dashboard.py
```

The dashboard will open in your browser at `http://localhost:8501`.

## Features

- **Arsenal Summary**: Usage rates, velocity, spin, movement metrics
- **Movement Analysis**: HB vs IVB scatter, spin rate distributions
- **Plate Discipline**: Zone rates, whiff rates, chase rates
- **Contact Outcomes**: GB/FB/LD rates, exit velocity, spray distribution

## Security

- **Internal use only** - No public endpoints
- **No experimental metrics** without approval
- **Confidential data** - Do not share externally
